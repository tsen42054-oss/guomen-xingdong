> 全民反走私，你我齐参与。

一款**反走私主题互动剧情 + 情景判断 + 益智闯关**的 H5 网页游戏，面向大学生及普通公众，用于反走私宣传与普法科普。

## 玩法介绍

玩家扮演**反走私宣传志愿者**，跟随三个关卡完成一次完整的"国门行动"，全场满分 100 分，共 14 道判断。

| 关卡 | 玩法 | 题量 | 计分 |
| --- | --- | --- | --- |
| 第一关 · 国门检查 | 港口情景三选一 | 5 | 每题 10 分 |
| 第二关 · 线索研判 | 线索卡片处置判断 | 4 | 最优 5 / 可行 3 / 欠妥 1 |
| 第三关 · 知识挑战 | 反走私常识选择 | 5 | 每题 6 分 |

## 功能特性

- 三关共 14 题完整流程，答题后即时显示解析与得分变化
- 积分系统、关卡进度条、HUD 显示
- 结局评级页：分数滚动动画、星级点亮、关卡得分明细
- 结局卡片：Canvas 绘制可下载 PNG，不支持时降级为可复制文案
- 音效由 Web Audio API 实时合成，不依赖任何音频文件，并提供开关
- 使用 localStorage 保存最高分 / 通关记录 / 音效偏好（不支持时自动降级，不会崩溃）
- 手机竖屏优先，兼容电脑浏览器，响应式布局
- 不要求登录，不收集任何个人信息

## 技术说明

- 原生 HTML5 + CSS3 + JavaScript，**单文件**实现
- 不使用 React / Vue / Node.js / 数据库 / 服务器
- 无任何外部依赖，无需联网即可离线运行
- 首页港口、国门、集装箱、海岸线等场景全部由 **CSS 与 SVG 手绘**，不含任何第三方图片素材

## 运行方式

1. 下载本仓库的 `index.html`
2. 双击用浏览器打开即可游玩（推荐 Chrome / Edge）
3. 手机端可将文件传入手机后用浏览器打开，或直接访问上方在线试玩链接
