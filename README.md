# 国门行动：暗线追踪 · 2D 探索版

> 全民反走私，你我齐参与。

一款**原创 2D 俯视角探索游戏**。玩家扮演港口巡查任务中的一名普通协助人员，在港口、仓储区与国门之间自由探索、收集证据、研判材料、选择处置方案，完成反走私宣传教育任务。

游戏**不使用答题、选择题、问卷或答卷式界面**——所有推进都通过角色移动、地图探索、场景互动、证据比对与任务决策完成。

## 玩法

| 关卡 | 场景 | 任务 |
| --- | --- | --- |
| 第一关 · 港口巡查 | 码头集装箱堆场 | 找到 4 条现场线索，与 2 位港区人员交谈，在任务终端提交记录，并选择**巡查收尾**处置方案 |
| 第二关 · 线索调查 | 仓储区域（可进入仓库） | 找到 3 份货物记录并归档，在**证据研判台**完成材料归类与关联，选择**材料移交**方案 |
| 第三关 · 守护国门 | 国门查验区（夜景） | 向 2 位现场工作人员汇报，**分配 6 点行动资源**，给出**最终处置意见**，完成抬杆放行 |

每关另有 2 份**可选宣传资料**，收集可提高综合评分。

## 操作

- **电脑**：`W A S D` / `方向键` 移动，`Shift` 快走，`E` 或 `空格` 互动，`Esc` 暂停，`Tab` 任务面板，`M` 音效开关
- **手机**：左下角虚拟摇杆移动，右下角金色按钮互动
- **HUD 按钮**：`案` 证据档案（带收集数量徽标）· `研` 证据研判台（第二关）· `资` 行动资源（第三关）· `♪` 音效 · `❚❚` 暂停

## 核心系统

- **持续运行的游戏循环**：`requestAnimationFrame` + 时间步长累加，帧率无关
- **瓦片地图**：40 × 28 格 / 每格 32px，三个关卡各一张独立地图
- **AABB 碰撞检测**：地形障碍 + 实体碰撞矩形（集装箱、建筑、隔离栏、车辆等），角色无法穿墙
- **摄像机跟随**：平滑插值 + 地图边界钳制，支持过场运镜
- **任务状态机**：`menu → playing → cine → clear → ending`，配合前置条件校验与防重复计数
- **弹层冻结**：研判台 / 资源分配 / 处置方案打开时世界停止推进，防止「看不见却在移动」
- **互动系统**：范围检测 + 就近选取 + 浮动标记 + 气泡提示
- **角色动画**：四方向朝向、行走摆臂摆腿、呼吸起伏、脚步扬尘粒子
- **任务简报 / 结算 / 结局**：关卡简报卡、结算徽章、星级点亮、结局卡片导出

## 结构化证据系统

线索收集已升级为**结构化证据系统**。每条证据包含六个字段：

| 字段 | 说明 |
| --- | --- |
| 唯一 ID | `E1` – `E8`，跨关卡唯一 |
| 标题 | 如「货物标签涂改痕迹」 |
| 描述 | 现场看到什么、玩家做了什么动作 |
| 来源 | 具体地点或口述人 |
| 核实状态 | 待研判 / 事实 / 推论 / 无关 |
| 关联证据 | 与该条相互印证的其他证据 ID |

证据档案位于 HUD 右上角 `案` 按钮（带收集数量徽标）。点击证据卡片可展开描述、来源、核实状态、研判说明与关联证据。

### 证据研判台（第二关）

- **证据归类**：把每条材料点进「事实 / 推论 / 无关」三个研判栏。直接观察并留证的客观情况归「事实」；由事实推测得出、仍需更多证据支持的归「推论」；与本次核查目标无直接关系的归「无关」
- **关联板**：点击两块相互印证的证据即可建立关联。预置 6 组正确关联（E1-E2、E1-E4、E1-E7、E3-E8、E6-E7、E7-E8），关联错误不扣分也不得分
- 归类与关联都完成后才能提交，**任务条件不会被跳过**

### 任务决策

- **处置方案**：每关结算前一次。第一关「巡查收尾」、第二关「材料移交」、第三关「最终处置意见」，每个方案 3 个选项，其中 2 个为规范做法
- **行动资源分配**：第三关最终任务前，把 6 点行动力分配到「提交证据档案 / 继续核实存疑信息 / 开展现场宣传讲解 / 自行返回堆场复查」四个环节

## 评分与结局

| 维度 | 权重 | 计算方式 |
| --- | --- | --- |
| 证据完整性 | 30% | 已入档证据数 / 全部证据数 |
| 推理准确性 | 30% | 归类正确率 × 60 + 关联建立率 × 40 |
| 处置规范性 | 25% | 规范方案数 / 总方案数（三关） |
| 资源管理 | 15% | 与推荐分配方案的偏差越小得分越高 |

- 全部得分经 `clampScore()` 做输入范围校验，恒为 0–100 的整数
- 计数由「按关累计结果」统一推导（`syncCounts()`），同一条线索只入档一次，**不存在刷分路径**
- 结算展示：四项得分条、关键决策解释、遗漏证据清单、研判偏差、改进建议、最终评级
- 四档评级：`S 国门守护先锋` / `A 反走私行动能手` / `B 反走私学习者` / `C 反走私初心者`

> **证据不足时选择「继续核实」不会被扣分**。第一关「暂不下结论、等待专业核实」和第三关「证据仍不完整，建议先补充核实」在设计上都被判定为**规范做法**，同样计入处置规范性得分。

## 视觉表现

- 全部由 **HTML5 Canvas 实时绘制**，不使用任何第三方图片
- 统一为现代港口行动风格配色：**深海军蓝 / 钢灰 / 警示橙 / 任务蓝**，主菜单、HUD、任务简报、证据面板、交互提示、结算与结局界面共用同一套设计变量
- 海面正弦波动 + 高光碎波、码头木栈前沿、码头石格、仓库屋顶（含空调机组与天窗）、集装箱（含波纹、角件与箱号牌）
- 三种时段氛围：第一关黄昏暖调、第二关白昼、第三关夜间灯光（暗场遮罩 + 灯光挖洞 + 角色随身光晕）
- 粒子系统：货轮烟囱白烟、脚步扬尘、线索收集火花、抬杆放行迸发
- HUD 显示关卡名、任务进度、宣传资料、证据入档数、用时与进度条

### 可进入的仓库

第二关的两座仓库不是实心屋顶，而是可以走进去的真实建筑：

- 三面外墙 + 南侧门洞，玩家需要从门洞进入，室内有货架、货垛与照明
- 室内地坪使用与室外明显不同的浅色混凝土地面，带伸缩缝与通道边线，一眼可辨室内外
- 关键记录分别放在两座仓库室内，因此**必须进入建筑**才能完成任务
- 室外屋顶不再绘制，室内内容完全可见

## 价值导向

剧情反复强调：**依法核查、保护证据、不随意指认他人、通过正规渠道报告可疑情况**。

- 闭锁的集装箱、锁扣松开的货箱：互动后玩家会主动收手，改为记录并通知工作人员，不擅自开封、不擅自搜查
- 老周的「这批货八成有问题」：玩家如实记录，同时注明这只是他的个人看法，不据此认定货物性质、不随意指认他人
- 试图绕开查验的车辆：不擅自追堵，把车牌、时间、位置交给有权部门
- 处置方案中「直接认定走私并查扣」「只移交自己认定的部分」「先向当事方透露判断」都被判定为**不规范做法**，并给出说明
- 所有证据一律通过任务终端 / 正规渠道提交，判断与处理交给有权部门

## 技术说明

- 原生 HTML5 + CSS3 + JavaScript，**单文件** `index.html`
- 不使用 React / Vue / Node.js / 服务器 / 数据库
- 无外部依赖，无需联网，双击即可运行
- 音效由 Web Audio API 实时合成，提供开关
- 使用 `localStorage` 保存通关进度、最好评级与音效偏好；不支持时自动降级，不影响游戏
- 手机竖屏优先（含安全区适配），同时兼容电脑浏览器
- 不要求登录，不收集姓名、身份证号、手机号等任何个人信息
